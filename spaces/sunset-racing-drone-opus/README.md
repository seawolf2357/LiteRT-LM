# SUNSET RACING — Drone

3D FPV drone race at sunset, built entirely by [Claude Opus 4.6](https://www.anthropic.com/claude/opus).
10 neon gates across the canyon, acro-mode controls (no self-level),
real-time lap delta.

**Keyboard** — W/S pitch, A/D yaw, Q/E roll, Space throttle up, Shift throttle
down, Tab camera, R reset, P/Esc pause, F fullscreen.

**Mobile** — Left stick: throttle + yaw. Right stick: pitch + roll.
